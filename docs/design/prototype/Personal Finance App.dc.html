Personal finance — offline, manual, honest

Built from the full spec pack — the canonical requirements v1.1, its six exceptions, and docs 01–19. Every figure is computed live by a metrics engine over {{ txCount }} seeded transactions, so every drill-down sums exactly to the transactions behind it.

Assumptions I made
  • Lifecycle stage: month 7 — six qualifying months, so typical, unusual spending and the insight set are all live. The stage now follows the data: switch the dataset in Tweaks to see the others.
  • Category icons are a lightweight stroked set drawn inline (doc 13 §5) — pickable when you create or edit a category.
  • Payee and account names are fictional sample data.
  • Tweaks switch the dataset between two years, seven months, the first week, and nothing recorded — so every stage of history, including the seasonal unlock at 24 complete months, is real rather than drawn.
  • Theme lives where the spec puts it: Settings → Preferences.
